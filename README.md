# 원물 시세 대시보드

Claude Artifact(claude.ai)에서 이전한 정적 웹 대시보드입니다.
`index.html` 하나로 동작하는 완전한 정적 페이지이며, 외부 서버나 빌드 과정 없이
어떤 정적 호스팅(GitHub Pages, Vercel, Netlify 등)에도 그대로 올릴 수 있습니다.

## 로컬에서 확인
그냥 `index.html`을 브라우저로 열면 됩니다.

## GitHub Pages로 배포하기
1. 저장소 Settings > Pages 메뉴로 이동
2. Source를 "Deploy from a branch"로 설정, 브랜치는 `main`, 폴더는 `/ (root)` 선택
3. 저장 후 몇 분 뒤 `https://<계정명>.github.io/<저장소명>/` 에서 접속 가능
